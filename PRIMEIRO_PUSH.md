# Primeiro envio do portfólio para o GitHub (uma vez só)

Analogia: o GitHub é uma vitrine na rua. Esta pasta é o estoque já embalado e etiquetado pelo Cronos. O arquivo `atualizar_portfolio.bat` é o funcionário que leva as caixas até a vitrine: confere se não há nada proibido, mostra a lista e só leva com o seu OK.

## 1. Conferir se o Git está instalado
Abra o Prompt de Comando (cmd) e digite:
```
git --version
```
Se aparecer um número de versão, siga. Se der erro, instale em https://git-scm.com (avance tudo no padrão).

## 2. Criar a vitrine no GitHub
1. Entre em https://github.com e clique em **New** (novo repositório).
2. Nome: `fermento`. Marque **Public**. **Não** marque "Add a README" (o nosso já existe).
3. Clique em **Create repository** e copie o endereço que termina em `.git`.

## 3. Enviar
1. Dê dois cliques em `atualizar_portfolio.bat`.
2. Cole o endereço quando ele pedir.
3. Confira a lista do que vai subir e digite `S`.
4. Se abrir uma janela de login do GitHub no navegador, faça o login: é o Git guardando a sua senha com segurança (Git Credential Manager). O Cronos nunca vê nem digita a sua senha.

## Atualizações futuras
Diga ao Cronos: **"Cronos, atualizar portfólio"**. Ele prepara o conteúdo sanitizado nesta pasta e avisa. Depois é só dar dois cliques no `.bat` de novo.
